# SWYNEX – Expense Tracker

SWYNEX is a responsive personal expense tracker built using HTML, CSS, and JavaScript. It helps users manage their income and expenses, track their balance, and visualize their financial activities.

## Features

- Dashboard overview of total balance, income, and expenses.
- Add, edit, and delete transactions.
- Search transactions by title.
- Filter transactions by type and category.
- Interactive charts using Chart.js.
- Store transaction data using Local Storage.
- Currency selection.
- Username management.
- Clear all transactions.
- Responsive design for desktop, tablet, and mobile.
- Hamburger sidebar navigation.
- Back to Top functionality.

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

##  How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in your browser.
3. You can also use the Live Server extension.

##  Data Storage

The application uses browser Local Storage to save transactions, username, and currency preferences. Data remains available after refreshing the page in the same browser.
